# 十四、【补充】数据模型

## Shopify 产品结构

```text
Product
├── title: “Solar Fence Light”
├── vendor: “LumaYard”
├── product_type: “Solar Lighting”  ← 对应 SHOP 分类
├── tags: [“backyard”, “fence”, “solar”, “shop-the-look-1”]
├── collections: [solar-lighting, backyard-space, featured]
├── variants:
│   ├── { title: “4-Pack / Black”, price: 39.99 }
│   ├── { title: “8-Pack / Black”, price: 69.99 }
│   └── { title: “12-Pack / Black”, price: 89.99 }
└── metafields:
    ├── space_type: “backyard,fence”       ← Shop by Space 过滤
    ├── look_id: “backyard-complete-look”  ← Shop the Look 关联
    └── features: “solar,usb-c,waterproof” ← 特性标签
```

## Collection 结构

```text
Collections（产品线）         Collections（空间）
├── solar-lighting           ├── space-backyard
├── rechargeable-lighting    ├── space-garden
└── garden-fences            ├── space-patio
                             └── space-deck
```

## Shop the Look 数据

存储为 JSON（Shopify Metaobject 或独立 API Route 配置文件）：

```json
{
  “look_id”: “backyard-complete-look”,
  “title”: “Complete Backyard Transformation”,
  “image”: “/looks/backyard-complete.jpg”,
  “hotspots”: [
    { “x”: 25, “y”: 60, “productId”: “gid://shopify/Product/1” },
    { “x”: 65, “y”: 45, “productId”: “gid://shopify/Product/2” },
    { “x”: 45, “y”: 80, “productId”: “gid://shopify/Product/3” }
  ]
}
```

## 技术 SEO

- 产品页：`next/metadata` 动态生成 title/description
- 图片：`next/image` + Shopify CDN，alt 文字包含关键词
- 结构化数据：`Product` schema（价格、评分、库存）
- `sitemap.xml`：Next.js 自动生成
- Core Web Vitals：目标 LCP < 2.5s（用 ISR 缓存产品页）

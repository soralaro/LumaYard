# 十四、【补充】技术选型决定

## 确定方案：Next.js (App Router) + Shopify Headless

原因：
- Shopify 处理产品目录、购物车、支付、订单管理 — 不重复造轮子
- Next.js 前端完全可控，可做高度定制的品牌体验（Day/Night 滑块、Shop the Look 热点等）
- App Router + React Server Components 保证 SEO 和性能
- AI Planner 未来直接作为 Next.js API Route 实现，无需迁移架构

架构图：

```text
Browser
   ↓
Next.js (Vercel)
   ├── App Router (SSR/SSG/ISR)
   ├── React Server Components
   └── API Routes
         ├── /api/planner    → AI Recommendation
         └── /api/vision     → Photo Analysis (future)
   ↓
Shopify Storefront API (GraphQL)
   ├── Products / Collections
   ├── Cart / Checkout
   └── Customer Accounts
   ↓
Shopify Admin
   ├── Order Management
   └── 3PL Fulfillment
```

技术栈：

| 层           | 技术                                  |
| ----------- | ------------------------------------- |
| 前端框架      | Next.js 15 (App Router)              |
| UI 组件      | Tailwind CSS + shadcn/ui              |
| 电商后端      | Shopify (Storefront API GraphQL)     |
| 部署          | Vercel                               |
| 图片          | Shopify CDN + next/image              |
| 状态管理      | Zustand (购物车状态)                   |
| AI (Phase 3) | Claude API (Vision + Recommendation) |
| CMS (Ideas)  | Shopify Blog 或 Contentful           |
| 分析          | Vercel Analytics + Google Analytics  |
